UGC List

Endpoint responsible for providing the list of UGCs stored in Mod_UI. The data can be returned in Lua or JSON, with an option to update the information using the latest Roblox data.

Endpoint

Use this endpoint to retrieve the UGC collection.

GET https://mod-ui.vercel.app/list

Parameters

The endpoint supports two optional parameters.

type=lua

Returns the UGCs converted into a Lua table, ready to be used in scripts.

type=http

Returns JSON through HTTP. Ideal for Roblox HttpService or external applications.

live=true

Retrieves UGC data through the configured API to obtain the latest available information.
