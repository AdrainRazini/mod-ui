UGC List

Endpoint responsável por fornecer a lista de UGCs armazenados no Mod_UI. Os dados podem ser retornados em Lua ou JSON, com opção de atualização através das informações atuais do Roblox.

Endpoint

Utilize este endpoint para obter a coleção de UGCs.

GET https://mod-ui.vercel.app/list

Testar API

Parâmetros

O endpoint possui dois parâmetros opcionais.

type=lua

Retorna os UGCs convertidos para uma tabela Lua, pronta para ser utilizada em scripts.

type=http

Retorna JSON através de HTTP. Ideal para Roblox HttpService ou aplicações externas.

live=true

Consulta os dados dos UGCs através da API configurada para obter informações atualizadas.
